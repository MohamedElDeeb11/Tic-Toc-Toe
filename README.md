# 🎮 Tic-Tac-Toe

A simple and fun **Tic-Tac-Toe game** built with **Flutter & Dart**.

## ✨ Features

* ❌ X vs ⭕ O
* 🏆 Winner detection
* 🤝 Draw detection
* 🔄 Restart game
* 📱 Simple & clean UI

## 🛠️ Built With

* Flutter
* Dart

## 🚀 Run

```bash
flutter pub get
flutter run
```
